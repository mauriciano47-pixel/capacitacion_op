# Capacitación Operador I.S. (`capacitacion_op`)

Plataforma Web interactiva de formación, entrenamiento en moldería NNPB, evaluación técnica y capacitación para Operadores I.S. de Cristal Chile.

## Características Principal

- 🎓 **Módulos de Formación NNPB & Soplo-Soplo:** Lecciones interactivas sobre el proceso de conformado de envases de vidrio.
- 🎯 **Simulador de Diagnóstico de Defectos:** Entrenamiento interactivo con el catálogo oficial de 96 defectos vidrieros.
- ⏱️ **Tiempos de Máquina I.S. & Calculadora SOP:** Ejercicios prácticos de calibración de soplado y temporización BDF.
- 📜 **Certificación y Evaluación de Competencias:** Pruebas de conocimiento técnico con bitácora de progreso.
